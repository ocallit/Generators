Tips

  • line-height:
    • Text: 1.5em to 1.6em
    • Heading: 1.1em to 1.2em
  • letter-spacing
    • Font Size 16px–20px do not change
    • Heading: letter-spacing: 0.05em;
    • Large title: -0.01em
  • Paragraphs: p { margin-top: 0; margin-bottom: 0; text-indent: 1.5em; /* Traditional indent size */ }
    p.first-para { text-indent: 0; }/* Remove indent from the very first paragraph of a chapter */
